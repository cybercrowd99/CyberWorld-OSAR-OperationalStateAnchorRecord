# CyberWorld-OSAR V1 — OSARAnchorRegistry

## Purpose

OSARAnchorRegistry defines the controlled registry responsible for maintaining all OSARAnchor references.

The registry preserves anchor continuity, retrieval, validation, lifecycle progression, and lineage.

OSARAnchorRegistry answers:

> Where is this anchor recorded, and what is its current operational status?

OSARAnchorRegistry is a registry mechanism.

It does not create:

- authority
- ownership
- identity
- operational conditions
- NET projections
- world state

The registry maintains anchor records only.

---

# OSARAnchorRegistry Doctrine

The registry is not the anchor.

The registry is not the authority.

The registry does not own represented objects.

The registry preserves:

- anchor continuity
- anchor lineage
- lifecycle progression
- retrieval integrity
